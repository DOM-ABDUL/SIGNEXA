# Dataset Storage Layout

Use this directory to organize legitimate ISL datasets once the team has obtained them with appropriate permissions.

Suggested structure:

training/datasets/
- raw/
- processed/
- features/

Meaning of each folder:

- raw/: original dataset files exactly as received.
- processed/: validated and cleaned intermediate files.
- features/: normalized ML-ready feature files.

No real dataset is currently included in this repository unless the team adds one explicitly.
